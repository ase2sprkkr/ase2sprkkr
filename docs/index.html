ASE2SPRKKR: SPR-KKR from Python and ASE

Ase2sprkkr is a modern, comprehensive replacement for XBAND, providing a unified framework for SPR-KKR calculations, ranging from easy interactive use to efficient, highly automated workflows on HPC systems. It integrates with the Atomic Simulation Environment (ASE) and supports preparing, running, and analyzing calculations through Python.

Why use it?

The underlying SPR-KKR package uses the Korringa-Kohn-Rostoker (KKR) multiple-scattering, Green’s-function approach. Its applications include density of states, Bloch spectral functions, magnetism, chemically disordered alloys (CPA), relativistic calculations and spectroscopy. The physics, approximations and numerical choices belong to the SPR-KKR manual; this documentation focuses on working with the software.

ASE2SPRKKR creates native SPR-KKR inputs and potentials from ASE structures, selects and configures tasks, starts calculations, and parses and visualizes supported results. The independent KKRunner package provides local, MPI, SSH and scheduler execution and optional persistent history. A separate ASE2SPRKKR GUI provides a graphical interface for preparing and managing calculations.

SPR-KKR executables are installed separately; ASE2SPRKKR does not include those binaries. Calculations are task-oriented (SCF, DOS, BSF, ARPES and others), and not every standard ASE calculator property is available.

Begin with First calculation: aluminium SCF and DOS to run an SCF-to-DOS example, then Installation and upgrading for configuration and upgrades, or Using ASE2SPRKKR for the Python API.

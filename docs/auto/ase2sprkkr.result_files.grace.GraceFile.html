class ase2sprkkr.result_files.grace.GraceFile(graphs=<factory>, settings=<factory>, commands=<factory>)[source]

Parsed Grace file; no matplotlib import or dependency.

Use GraceFile.from_file(path) or GraceFile.from_string(text). graphs[1].datasets[0].data retrieves the data for G1.S0. datasets is a mapping from G*.S* identifiers to datasets.

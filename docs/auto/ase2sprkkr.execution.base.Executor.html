recover_submission(run_id, submission, *, submitted_at=None)[source]

Recover a submit whose backend reference was not persisted.

submitted_at is the timestamp at which ASE2SPRKKR reserved the submission. Scheduler backends may use it to bound accounting-history queries after a job has left the live queue.

Return a status with a reconstructed backend reference when the submit is found, None only when the backend can positively establish that it does not exist, and raise NotImplementedError when this backend cannot perform such recovery. Transport/backend failures should propagate rather than being mistaken for absence.

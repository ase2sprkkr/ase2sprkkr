definitions

Full name: ase2sprkkr.input_parameters.definitions

Description

Input-parameter schema definitions.

Each public module exposes input_parameters_definition. Standard schemas attach their 1:1 task as _task_definition; schemas shared by several tasks leave it unset and resolve task names from concrete parameter values.

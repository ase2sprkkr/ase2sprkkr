_task_definition = None

1 task declared together with this schema.

This is declaration-time metadata for the simple case where one input schema represents exactly one task. Schemas shared by multiple tasks leave it as None and override task_definition_name() using their values.

The association is internal and must not be changed after registration.

task_definition_name(parameters)[source]

Return the ASE2SPRKKR task name represented by parameters.

The standard one-schema/one-task case is answered directly by the schema declaration. Shared schemas override this method and derive the identity from concrete parameter values. Resolving the returned name to a TaskDefinition remains the responsibility of TaskRegistry.

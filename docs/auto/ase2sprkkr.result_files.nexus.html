nexus

Full name: ase2sprkkr.result_files.nexus

Description

Export native SPR-KKR ARPES SPC data as NeXus/HDF5.

The SPC file owns sampled intensities and coordinates. InputParameters owns the specified experiment settings. This module does not recompute KKRSPEC spin, photon, or reciprocal-space transformations.

remote

Full name: ase2sprkkr_cli.commands.remote

Module class hierarchy


Description

Human-facing run observation, deliberately independent of KKRunner’s CLI.

KKRunner owns execution identity, persistence, and byte transport. This CLI owns argparse, run selection, SCF interpretation, and text filtering.

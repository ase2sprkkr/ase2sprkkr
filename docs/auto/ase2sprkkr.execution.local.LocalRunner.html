LocalRunner

class ase2sprkkr.execution.local.LocalRunner(reader, spec, callback=None)[source]

One local subprocess execution.

The runner owns process lifecycle, cancellation, output-file writing and delivery of raw stdout/stderr to listeners. The output reader only parses streams and builds the TaskResult.

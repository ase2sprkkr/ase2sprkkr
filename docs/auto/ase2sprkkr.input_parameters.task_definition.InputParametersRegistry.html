read_for_task(task, file, *, input_definition=None, allow_dangerous=False, allow_incomplete=False, report_invalid=None)[source]

Read input with an exact schema and require it to represent task.

input_definition is primarily for historical reconstruction: when omitted, the task’s current declared schema is used. Passing a schema name or definition selects that exact schema. An explicit definition object may intentionally be unregistered, which supports experimental or custom parsers while retaining the task-identity check.

In strict mode the expected task is not supplied as parsing context. In incomplete mode it is available to callable defaults, but any explicit selector in the file must still agree with the expected task. This allows recovery of a partial file without silently overriding a conflicting task identity.

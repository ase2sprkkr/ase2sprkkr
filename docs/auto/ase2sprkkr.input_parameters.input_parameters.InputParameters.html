InputParameters

class ase2sprkkr.input_parameters.input_parameters.InputParameters(definition, inputfile=None, outputfile=False, *, task_name=None)[source]

Concrete values of an SPR-KKR input file.

Input-file schemas and task identities are separate registries. Standard schemas carry their canonical task directly; shared schemas resolve the task from their concrete values.

save_to_file(file, atoms=None, *, validate='save')[source]

Save the configuration to a file in a given format.

This routine do some basic stuff and then call _save_to_file routine, that contains the implementation specific for the type of the configuration container/value.

Parameters:

  • file (str or file) – File to read the data from

  • validate – Validation mode. True and "save" perform strict save validation, False skips validation, and "warning" performs save validation without raising DataValidityError results. "set" can be used to allow values that are only required when saving.

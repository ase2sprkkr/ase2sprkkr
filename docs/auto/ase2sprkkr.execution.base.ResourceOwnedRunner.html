ResourceOwnedRunner

class ase2sprkkr.execution.base.ResourceOwnedRunner(runner, resources)[source]

Runner proxy owning resources and the public submit/cancel boundary.

Resources remain owned by the caller until this proxy is constructed. From that point they are released on completion, on a synchronous submission failure, or explicitly through close() while the run is still new.

Cancellation is latched and thread-safe even before submission. If cancel() wins the race with submit(), the backend runner is not submitted and submit() raises asyncio.CancelledError. If the request arrives while backend submission is already in progress, cancellation is dispatched exactly once after that submission boundary completes.

RepeatedNumberedIf

class ase2sprkkr.common.repetition.RepeatedNumberedIf(condition)[source]

Dense repetition whose output numbering is selected at runtime.

The parser accepts both NAME and NAME<number> because the option controlling the condition may occur later in the input. Values are always stored as an array; condition(option) only controls validation and the spelling used for output.

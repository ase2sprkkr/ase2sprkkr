Transport

class ase2sprkkr.execution.transport.Transport[source]

Run commands and move files on one target machine.

Transport operations are asynchronous because remote execution is mostly I/O. put_file() and get_file() are exact one-file primitives. put_files() and get_files() accept one path/pattern or an iterable and preserve each matched file’s path relative to the supplied source root. Wildcards are always expanded on the source side of the transfer.

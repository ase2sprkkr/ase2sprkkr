ConfigurationTransaction

class ase2sprkkr.common.configuration_transaction.ConfigurationTransaction(configuration, policy=None)[source]

Context manager for temporary configuration mutations.

Staged objects hold their proposed state directly, so ordinary container traversal sees the complete proposal. A normal context exit commits all staged objects; an exceptional exit rolls them back in reverse order.

Mutable values are the real objects. Their in-place mutations deliberately cannot be rolled back by this transaction.

classmethod use(configuration, policy=None)[source]

Return a context for the transaction applicable to configuration.

An active transaction is entered as a nested savepoint; otherwise a new transaction is returned. A failed nested operation rolls back only its own changes unless its exception escapes the outer transaction. policy is used only when a new transaction is created; nested operations share the policy of the active transaction.

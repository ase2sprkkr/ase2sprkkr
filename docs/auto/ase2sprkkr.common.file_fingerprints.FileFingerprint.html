FileFingerprint

class ase2sprkkr.common.file_fingerprints.FileFingerprint(device, inode, mode, size, mtime_ns, ctime_ns)[source]

Metadata identity of one filesystem object at one point in time.

This intentionally avoids reading file contents. It is suitable for detecting ordinary replacement or rewrite races around potentially large SPR-KKR files, not for cryptographic content identity.

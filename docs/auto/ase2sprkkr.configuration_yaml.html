configuration_yaml

Full name: ase2sprkkr.configuration_yaml

Description

YAML persistence helpers for the ASE2SPRKKR configuration.

The YAML document is kept separate from the typed configuration. Loading first tries the whole document atomically; if a user-data error is found, valid fragments are recovered while invalid/unknown raw nodes remain available for round-trip persistence.

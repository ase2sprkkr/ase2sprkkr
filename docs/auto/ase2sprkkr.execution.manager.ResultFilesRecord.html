ResultFilesRecord

class ase2sprkkr.execution.manager.ResultFilesRecord(input_file=None, output_file=None, input_files=(), output_files=(), input_fingerprints=(), fingerprints=(), captured_at=None, state=ResultFilesState.CURRENT, retrieval_state=None, retrieval_message=None)[source]

Persistent file manifests and snapshots captured at finalization.

fingerprints describe calculation outputs and determine state. input_fingerprints preserve reconstructable historical input context, but an unavailable/changed input does not invalidate output that is still current. Cache files are intentionally absent because reusable caches may legitimately be updated by later calculations.

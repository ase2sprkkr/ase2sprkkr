ExecutionManager

class ase2sprkkr.execution.manager.ExecutionManager(store=None, *, executor_pool=None, submitting_grace=60.0)[source]

Orchestrate optional persistent run bookkeeping.

The manager owns persistent records, not live runners. Returned PersistentRunner objects remain owned by their callers. Executors are process-wide pooled by persisted endpoint identity, independently of this manager and its store.

Attach to a stored run using an explicitly supplied output reader.

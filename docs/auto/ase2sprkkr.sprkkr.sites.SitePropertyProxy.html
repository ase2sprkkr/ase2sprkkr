SitePropertyProxy

class ase2sprkkr.sprkkr.sites.SitePropertyProxy(site, getter)[source]

Generic proxy for a SiteType-delegated property (mesh, potential, charge, moments, reference_system) that intercepts in-place attribute mutations and calls site.break_symmetry() first, ensuring the change only affects the individual site rather than all symmetry-equivalent sites.

Only instantiate when the underlying value is not None; return None directly for None-valued properties so that site.potential is None keeps working.

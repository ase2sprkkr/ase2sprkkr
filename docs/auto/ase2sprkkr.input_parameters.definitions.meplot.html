meplot

Full name: ase2sprkkr.input_parameters.definitions.meplot

Module class hierarchy


Description

Dipole matrix-element plots, based on ME_PLOT in SPR-KKR 9.7.

BAND scans initial electron energies at fixed photon energy, or photon energies at one initial electron energy. CORE scans final electron energies. The source fixes m_j=1/2 and polarization q=0; neither is an input parameter.

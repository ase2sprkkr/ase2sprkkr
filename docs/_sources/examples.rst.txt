Examples by application
=======================

Each example below includes its Python source code, a download link
and a link to module documentation. The examples come directly from
``src/ase2sprkkr/examples/`` so the displayed code follows the source.

For a first calculation, follow :doc:`quickstart`. They demonstrate API use rather than numerically converged reference
calculations. Some require additional programs or optional Python packages.
Review numerical parameters before using them in production.
For scientific assumptions and parameter convergence, consult the
`SPR-KKR manual <https://sprkkr.org/manual/>`_.

The command-line interface can list, show and copy the same examples::

   ase2sprkkr example
   ase2sprkkr example --regex 'Fe|DOS'
   ase2sprkkr example 1
   ase2sprkkr example 1 --copy ./my-example

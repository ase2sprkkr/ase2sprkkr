Changelog

Version 4.0.0 (beta series)

Version 4.0.0 is a major refactoring of ASE2SPRKKR, extending the available SPR-KKR tasks, calculation execution, result processing and GUI integration. The highlights below summarize the beta series; the release-specific notes retain the detailed technical changes.

SPR-KKR tasks and input parameters

  • Added more than 40 native task definitions based on the SPR-KKR sources. Many of the advanced tasks are experimental.

  • Separated native task identity from reusable input-parameter definitions. Multiple tasks can share a schema: BSFEK and BSFKK share the BSF input parameters, while JXC and DMI select different task modes through a common definition.

  • Improved task validation, dependent and optional parameters, user-defined input-parameter presets and canonical task handling.

  • Tasks now declare their known input, output and auxiliary/cache files for result discovery, postprocessing and remote file management.

Completely redesigned execution

  • Rewrote SPR-KKR program execution around the independently distributed kkrunner run manager, which also supports other scientific programs.

  • Added local and remote execution over SSH, MPI launchers, and optional scheduler support, including Slurm through PSI/J.

  • Added project databases that retain calculation records, statuses and files, with reconnection to supported running jobs after client restart. Project history is particularly useful for the GUI, but is also accessible from Python and the command line.

  • Added named execution profiles stored in YAML configuration, and output filtering using regular expressions.

Symmetry, plotting and GUI support

  • Added ase2sprkkr symmetry for crystallographic space-group analysis, site equivalence, symmetry operations and cell transformations.

  • Added parsing and direct plotting of SPR-KKR Grace .agr files through ase2sprkkr plot.

  • Added ARPES SPC-to-NeXus/HDF5 export through ResultFile.to_nexus() and the new ase2sprkkr nexus SPECTRUM.spc command. The export preserves native spectra and physical axes and includes available calculation provenance and descriptive metadata. The NeXus writer’s optional dependencies are provided by ase2sprkkr[nexus].

  • Added APIs for calculation preparation, monitoring, persistent project history and result-file actions used by the separately published ase2sprkkr-gui desktop application.

Compatibility

  • Python 3.9 or newer is required. Version 3.6.0 is the final stable release supporting Python 3.8 and the last release before this architectural refactoring.

  • kkrunner is a required dependency; the execution and task-definition APIs have changed substantially from the 3.x series.

Version 4.0.0-beta4

ARPES NeXus export

  • Added ase2sprkkr nexus SPECTRUM.spc to export native ARPES SPC spectra to NeXus/HDF5; -o/--output selects the output file and -i/--input-file supplies the original SPR-KKR input when available. Without -o, the command writes beside the SPC file using .nxs. Dependencies for exporting are optional (ase2sprkkr[nexus]).

  • Enriched ARPES NeXus exports with physical-axis labels and HDF5 dimension scales, descriptive signal units and names, exporter details, native SPC header/column provenance and available input parameters, without changing sampled intensities or axis ordering.

Version 4.0.0-beta3

Results and plotting

  • Added parsing of Grace .agr result files into graph and dataset models, with Matplotlib plots including multiple panels.

  • Added AGR support to ase2sprkkr plot and result-file plot actions.

  • Exposed existing task-declared output files in parsed scientific results, including files that do not have specialized result parsers.

  • Improved historical result loading when auxiliary files are missing or stored input-parameter schemas differ from the current definitions.

Execution and fixes

  • Persisted resolved execution-profile identity and application metadata with project runs.

  • Updated the required kkrunner version to 0.2.0b2.

  • Fixed output-file discovery, historical-result and CI regressions.

Version 4.0.0-beta2

Execution and remote monitoring

  • Adopted the KKRunner 0.2 execution architecture, including independent backends and transports and Run-owned resources.

  • Improved persistent run recovery, result reconstruction, execution lifecycle handling and integration with direct, supervised and PSI/J jobs.

  • Added SPR-KKR-aware ase2sprkkr remote status and ase2sprkkr remote follow commands, with SCF iteration progress and historical output handling.

Command line and compatibility

  • Added third-party command discovery through the ase2sprkkr:cli entry-point group.

  • Continued extraction of the lightweight ase2sprkkr_cli package.

  • Improved NumPy compatibility, execution test coverage and resource cleanup.

Version 4.0.0-beta1

Execution, remote calculations and projects

  • Managed local and remote calculations with asynchronous execution, status monitoring, output following, cancellation and persistent run history.

  • The independent kkrunner package provides the execution layer. ASE2SPRKKR prepares SPR-KKR inputs and interprets scientific outputs; KKRunner manages processes, MPI, SSH, schedulers, file transfers and run state.

  • SPRKKR.create_run() separates preparation, submission and waiting (submit() and wait()) while SPRKKR.calculate() remains available for synchronous calculations.

  • Host-aware MPI launchers, including srun in Slurm allocations and mpirun/mpiexec elsewhere.

  • Remote execution over SSH, with remote working directories, input staging, output retrieval, configurable synchronization policies, and remote executable and MPI configuration.

  • Optional PSI/J scheduler integration, including Slurm, via the psij extra, with scheduler-specific resources and backend behavior.

  • Persistent project-based calculations with durable run identities, statuses, execution records and calculation history; tracking is opt-in.

  • Reconnection to active jobs after client restart, resumption of interrupted downloads and explicit postprocessing retries without resubmitting SPR-KKR. Recovery depends on backend capabilities.

  • Historical TaskResult reconstruction using TaskResult.from_run() or load_project_result(); attach_project_run() reconnects active persistent project runs.

  • Declarative task input/output/cache file manifests, including optional files and wildcard patterns, synchronization policies and integrity checks to detect missing or overwritten historical results.

  • Managed stdout/stderr and output listeners. ase2sprkkr remote provides user-facing status, follow and cancel commands; the execution protocol uses kkrunner remote.

Configuration and profiles

  • YAML user configuration and named execution profiles for executable locations, MPI, local/SSH/scheduler backends, remote directories, filesystem identities and file synchronization settings.

  • Migration from legacy Python configuration with ase2sprkkr config --migrate; extended CLI to list, inspect and edit profiles and their settings.

  • Profiles and per-calculation overrides can select execution backends without changing task input parameters.

New and extended SPR-KKR tasks

  • More than 40 new native task input definitions, many experimental. ase2sprkkr info lists stable tasks before experimental ones; definitions do not imply numerical validation of every advanced mode.

  • Photoemission, spectroscopy and related tasks: AES, APS, NRAES, AIPES, BAND, SPLEED, CLPES, CLXPS, VBPES, XES, XRS and CHIXAS.

  • Magnetic response, optical and transport tasks: CHI, CHILANDAU, SIGMA, OPTABS, T1, NUCSSCPL, STONER, SOCPAR, FMAG and COMPTON.

  • Electronic-structure, scattering and current-density tasks: BONDING, BSDOSIJ, FSCAT, EKREL, JALF, JORB and TDOBS.

  • Positron workflows: POSANIPREP, POSANITAU and POSANI.

  • Plotting and diagnostic tasks: PLOTPRS, PLOTPOT, PLOTRHO, PLOTSFN, PLOT2DPR, PLOT2DPOT, PLOT2DRHO, WFPLOT, MECHECK, MEPLOT, PSHIFT and TUTORIAL.

  • BSF modes have separate BSFEK and BSFKK task identities sharing the BSF input schema; BSF validation and k-paths improved.

  • Existing SCF, DOS, ARPES, PHAGEN, JXC, XAS, GILBERT and other definitions received improved options, default values, validation or declared files.

  • Task identity and executable metadata separated from reusable input parameter schemas; user-defined presets preserve canonical task identities instead of introducing unwanted new tasks.

  • Task-specific input, output and cache declarations, including conditional filenames, DATASET/ADSI and TAUDIR/TAUPATH handling.

  • Support for reading incomplete input files with warnings, conditional requiredness, and cross-section validation of dependent options and array lengths.

Symmetry and structure tools

  • New ase2sprkkr symmetry command and analyze_symmetry() API for spglib-based space-group and site-symmetry analysis without modifying or retaining the input Atoms object.

  • Primitive and standardized conventional cell transformations, optional idealization, and policies for preserving SPR-KKR site metadata and extra ASE arrays.

  • Equivalent sites, Wyckoff positions and symmetry operations can be displayed, with optional JSON report output.

  • CIF-declared symmetry is reported separately from calculated symmetry, including detection of differing space-group numbers.

Results and plotting

  • Structured result files exposed as ResultFile from ase2sprkkr and ase2sprkkr.result_files. The top-level OutputFile remains available as a deprecated compatibility alias.

  • SFN file reading, writing and plotting, explicit SFNFIL selection, and information about SFN file generation.

  • SCF parsing supports runs without EMIN (thanks to Chriss Woodgate).

  • ARPES results provide all polarization spectra through ArpesResult.spectra; NeXus/HDF5 export with metadata and interactive ARPES plotting controls.

  • print_output supports informational output, regular expressions and custom output listeners.

  • Corrected DOS, BSF and ARPES arithmetic, DOS energy handling, and Gaussian and Lorentzian spectral broadening.

Calculator and command-line interface

  • SPRKKR.prepare() generates scientific calculation inputs without submitting a run.

  • Explicit restart_scf option to control SCF restarts.

  • Unsuccessful synchronous calculations raise ASE’s CalculationFailed instead of updating calculator state as if the calculation had succeeded.

  • Lightweight ase2sprkkr_cli package now implements the CLI entry point, with lazy imports of command-specific functionality.

Compatibility

  • Python 3.8 support dropped; Python 3.9 or newer required.

  • kkrunner is a required dependency; scheduler integration uses the optional psij extra.

  • ArpesResult.spc deprecated in favor of ArpesResult.spectra.

  • Legacy execution-related configuration options are deprecated in favor of named profiles.

Internals

  • Transactional configuration updates and cross-section validation.

  • Refactored dependent, repeated and generated configuration values, including NumPy arrays with specified or dependent line counts.

  • Optional fast parsing of simple numerical arrays via numpy.fromstring, with fallback for incompatible input formats.

  • Reorganized task and result-reader registries, with SPR-KKR file metadata and result reconstruction in ASE2SPRKKR and generic execution state and persistence delegated to KKRunner.

  • Improved symmetry/site-equivalence handling and regression tests.

  • Various bug fixes and compatibility improvements.

Version 3.6.0

This is the final stable release of the original ASE2SPRKKR architecture before the major 4.0.0 refactoring, and the last release supporting Python 3.8. Users needing Python 3.8 or the previous execution architecture should remain on the 3.6.x series.

  • Added support for ANDERSON mixing (experimental), BSF task improved

  • A better debugging in ase2sprkkr shell

  • promote_ase_atoms can be directly imported from the ase2sprkkr root package

  • Changing properties via site is disallowed in cases where site_type is shared

  • JXC output file parsing and plotting

  • XAS output file parsing and plotting

  • Beyond-DFT parammeters (DFTM, DFT+U,…)

  • Hyperfine-field switches

  • Semi-infinite structure building improved

  • Uppasd improvements: direct calling of sd, input file stub writing

  • Improved layout for multiple plots

  • Additional values parsed for SFC task

  • Tool: Python-like output for ase2sprkkr k-path tool

  • Tool: ase2sprkkr example search (–regex) and example display

  • Tool: ase2sprkkr shell –pdb for running examples in the Python debugger

  • Tool: ase2sprkkr plot -V <filename> for showing plottable values in a file

  • Improved Hall number determination from Cell

  • Docstrings added for examples

  • Various bug fixes

  • SLURM work manager auto-detection

  • Examples from ASE2SPRKKR article were added

Internals

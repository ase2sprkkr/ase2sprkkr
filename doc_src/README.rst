Execution and persistent runs
==============================

The separate `KKRunner library <https://ase2sprkkr.github.io/kkrunner/>`_ owns
processes, SSH/scheduler execution, manifests, transfers and durable history.
ASE2SPRKKR prepares SPR-KKR inputs and constructs scientific results. See the
`application execution guide <https://ase2sprkkr.github.io/ase2sprkkr/execution.html>`_
for project runs, reconnect, profiles and historical result loading.
